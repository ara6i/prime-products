# PDP Studio Design System

## Visual contract

- Layout and density follow the supplied PhotoRoom desktop reference.
- Color and product identity remain PrimeStyleAI: white workspace, cool neutral surfaces, cobalt actions.
- Product imagery uses realistic commercial photography with natural materials and neutral color.

## Desktop geometry

- Sidebar: `248px`
- Top bar: `81px`
- Main horizontal padding: `32px`
- Upgrade banner: `97px` high, `10px` radius
- Quick tools: five columns, two rows, `66px` high, `12px` gaps
- Workflow rail: `368px` cards, `12px` gaps, horizontal overflow
- Workflow image: `190px` high
- Workflow caption: `64px` high
- Major section gap: `50px`

## Type scale

| Role | Size | Weight |
| --- | ---: | ---: |
| Page title | `24px` | `600` |
| Banner title | `24px` | `600` |
| Section title | `16px` | `600` |
| Workflow caption | `16px` | `600` |
| Navigation | `14px` | `500` |
| Banner/body copy | `14px` | `400` |
| Tool label | `12px` | `500` |
| Badge/meta | `9–11px` | `500–600` |

The PDP Studio shell uses Inter/system sans for compact UI text. Poppins remains reserved for the PrimeStyleAI wordmark.

## Surface rules

- Default card radius: `8px`
- Large surface radius: `10px`
- Borders: one quiet neutral rule; no heavy outlines
- Shadows: reserved for overlays and subtle card hover only
- Icons: Phosphor regular weight, normally `19–20px`
- Blue belongs to actions, selection, and focus—not the product photography
