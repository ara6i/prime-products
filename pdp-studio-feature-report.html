Generation Dialog Pattern

Shared controls

  • Switch tool selector inside the modal.
  • Drop zone for file upload.
  • Single-image and multi-image inputs depending on tool.
  • Add-more-images control where multiple source angles are useful.
  • Quality selector, commonly defaulting to standard.
  • Output size selector: square, portrait, landscape, and other ratios.
  • Brand style toggle, defaulting off when no brand kit is applied.
  • Prompt box for optional instructions.
  • Generate button disabled until required input is present.
  • Generation quantity shown in the button label.
  • Tool-specific description at the bottom of the modal.

Advanced controls seen in specific tools

  • Model selector for virtual model generation.
  • Pose selector for virtual model generation.
  • Background selector for model/product scenes.
  • Template selector for video generation.
  • Style selector for text-to-image generation.
  • Prompt inspiration chips for starting a generation.
  • AI credit notice for video generation.

Background, Model, and Pose Controls

Background selection

  • Clean studio backgrounds: white, grey, beige, pastel yellow, pastel orange, pastel green, pastel blue, and pastel pink.
  • Classic PDP backgrounds: white, black, transparent, and original image.
  • Scene backgrounds for lifestyle product staging.
  • Random background option for faster creative exploration.
  • Prompt-based background description for custom PDP scenes.
  • Batch background presets so many product images can share the same studio style.

Model selection

  • Virtual model selector for apparel and wearable product images.
  • Default model option observed in the model tool.
  • Model choice is part of the generation controls, not only a prompt.
  • Useful for PDP images where the merchant needs a consistent on-body presentation.
  • Can be mapped to our existing try-on/model-selection flow.

Pose selection

  • Pose selector for virtual model images.
  • Random pose option for quick variant generation.
  • Pose can be used to create PDP gallery variety: front, angled, seated, walking, hand detail, or lifestyle stance.
  • Pose preservation will need validation so the product does not distort during generation.

How this helps PDP

  • Create a consistent product page set from one source image.
  • Generate hero, gallery, lifestyle, and social crops with controlled background and pose.
  • Keep brand style consistent across all product images.
  • Let merchants regenerate only the background, model, or pose without restarting the whole workflow.

Batch Editing Features

  • Edit up to 250 images at once.
  • Import individual images.
  • Import a folder.
  • Drag and drop images or a folder onto the page.
  • Apply background and studio presets to many images.
  • Batch preset sections include essentials and studio backgrounds.

Features We Can Build

The current stack already has a prompt system, OpenAI/Gemini access, PDP Studio test lab, image inputs, product image input, model selection, and generation result display. The work should build on those instead of creating a separate disconnected tool.

PDP-specific features

  • Build now: PDP hero image generator from one product image, with clean studio, lifestyle, flat lay, and model-worn output modes.
  • Build now: PDP gallery set generator that creates a full product page image pack: hero, close-up, lifestyle, scale/context, detail shot, and social crop.
  • Build now: Shopify-ready export sizes for product cards, product detail hero, gallery thumbnails, collection images, and social preview images.
  • Build now: product fidelity rules that keep shape, color, logo, texture, material, and key details stable across generated variants.
  • Build now: prompt presets by product type: apparel, shoes, accessories, beauty, home goods, packaging, and generic ecommerce products.
  • Build now: catalog product import so the studio can start from existing Shopify products, demo products, uploaded images, or detected product records.
  • Build now: before/after comparison and variant picker so a merchant can select which generated images should be used on a product page.
  • Build now: regenerate same PDP shot with a different background, angle style, model, pose, crop, or marketplace size.
  • Build now: save generated images back to product history with product ID, SKU, prompt settings, model used, cost estimate, and selected export size.
  • Needs careful validation: automatic publishing to Shopify PDP media should wait until review, rollback, and duplicate-detection are implemented.

Core workspace

  • Build now: dashboard shell with sidebar, search, tool shortcuts, modal auth, and direct editor link.
  • Build now: saved project/design history for generated PDP images.
  • Build now: tool switcher inside one studio modal, using the current PDP Studio generation flow.
  • Build now: recent tools section based on local/user history.
  • Build now: prompt presets mapped to tool type.

Product image tools

  • Build now: Product Staging for lifestyle PDP scenes using product image + prompt + background/size controls.
  • Build now: Product Beautifier for cleaner product shots using a fixed enhancement prompt template.

Recommended Build Order

  1. Finish the dashboard, auth modal, and protected editor routing.
  2. Convert the current PDP Studio test lab into a reusable editor component.
  3. Add PDP hero, PDP gallery set, Shopify size presets, and product fidelity prompt rules first.
  4. Add tool switcher, prompt mapper, and tool-specific system prompts.
  5. Add output size, quality, brand style, and generation count controls.
  6. Ship Product Staging, Product Beautifier, Studio Shot, Virtual Model, Ghost Mannequin, Flat Lay, and Edit with AI first.
  7. Add saved generations, product history, and variant picker.
  8. Add Shopify/catalog product import into the studio.
  9. Add batch generation with backend queue and live job status.
  10. Add marketplace export presets and download bundles.
  11. Add advanced deterministic tools: remove background, resize, expand, shadow, retouch, and product fixer.

Implementation Notes

  • Keep the page server-rendered and move UI into components.
  • Keep browser logic in hooks, especially uploads, modal state, generation state, and polling/SSE.
  • Use mappers for tool definitions, prompt templates, output size presets, and marketplace presets.
  • Keep PDP Studio accounts separate from customer dashboard accounts unless a shared account strategy is intentionally chosen later.
  • Store each generation with tool type, source images, prompt variables, final prompt, model, size preset, cost estimate, result URL, and product reference.
  • Use the existing OpenAI/Gemini prompt system for high-level generation and add deterministic image-processing services only where needed.
