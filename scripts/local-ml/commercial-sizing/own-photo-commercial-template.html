How we calculate it

  1. Use a person’s saved waist and hip to choose a starting size from the real product chart.
  2. Add the selected error to waist, hip, or both. For example, 80 cm becomes 83 cm at +3 cm.

  4. Count the result as same size, size up, size down, or no size.

How we calculate it

  1. Choose one person and one AI measurement model: Aiad or V8.
  2. For every photo, compare the model’s waist and hip answer with that photo’s saved real tape.
  3. Show the centimetre error. Example: real waist 94 cm and AI waist 96 cm means the AI is 2 cm too large.
  4. On each product, use the real tape to choose the starting size. Then use the AI measurements on the same product chart.
  5. If both choose M, that product is one “same size” match. If real tape chooses M and AI chooses L, it is not a match.
What the percentage meansThe percentage is product-size agreement, not measurement accuracy. Example: if real tape can choose a size on 90 products and the AI chooses the same size label on 72, the report shows 72 ÷ 90 = 80%. A smaller tape error can still cross a chart boundary. A 2 cm error can keep the same size on one chart and cross into another size on a different chart.

No extra ±1–7 cm error is added to Aiad or V8. This report uses each model’s actual saved prediction. The camera option only shows separate A-to-B and pose diagnostics; it does not change the official measurement or size result.

What we built and tested

V8 learned from real answers, then this report checks its finished answers. The report does not train V8.

1. InputV8 receives the black-and-white body mask plus height, weight, BMI, and gender.
2. TeacherWEAR’s real waist and hip tape answers, plus the checked 3D training geometry.
3. StudentV8, the computer model learning to predict waist and hip.
4. TrainerOur Python program gives V8 an input, asks for an answer, and compares it with the teacher.
5. PyTorchThe software that runs V8’s calculations on the CPU or GPU.
6. LossThe mistake number. If V8 says 80 cm and the teacher says 85 cm, it records that difference.
7. GradientPyTorch calculates which internal numbers should move up or down to reduce that mistake.
8. AdamWThe training tool that applies those small number changes before V8 tries again.
9. WeightAn internal number saying how strongly one learned clue should affect V8’s answer.
10. BiasAn internal number that adds a small starting increase or decrease inside a calculation.
How V8 was separated3,451 people taught V8. A different 427 people checked which saved V8 version was best. A separate 448 people were kept for the final unseen test.
What this page is doing nowIt compares frozen Aiad or V8 answers with saved tape on __CAPTURE_COUNT__ photos from __IDENTITY_COUNT__ people, then tries those measurements against 100 gender-matched products per photo. AdamW is not running on this page. We run Aiad’s frozen package here; we did not retrain it and its original training loop was not provided.
